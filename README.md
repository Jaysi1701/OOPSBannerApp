# 🎯 OOPS Banner App (Java)

## 📌 Overview

A Java project that prints **"OOPS" in banner format** using ASCII characters. It demonstrates the step-by-step application of **Object-Oriented Programming (OOP)** concepts.

---

## 🚀 Features

* Console output of "OOPS"
* ASCII banner rendering
* Use of arrays, loops, and methods
* Implementation of OOP principles
* Efficient string handling with `StringBuilder`
* Scalable design using `HashMap`

---

## 🧠 Concepts Used

* Class & Main Method
* Strings & Arrays
* Loops
* Methods (Modularity)
* OOP (Encapsulation, Abstraction)
* HashMap & StringBuilder

---

## 💻 Run the Program

```bash
javac OOPSBannerApp.java
java OOPSBannerApp
```

---

## 📌 Outcome

Demonstrates how a simple program evolves into a **modular, reusable, and efficient OOP-based solution**.
